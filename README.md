# ???? English Documentation

## ?? Overview
**ChromaNet** is an end-to-end deep learning framework designed to automatically restore and synthesize realistic colors in grayscale images. Leveraging a symmetric **Deep U-Net (Convolutional Autoencoder with Skip Connections)**, ChromaNet learns the complex mapping from luminance/intensity channels to full RGB chromatic spectra across diverse visual domains (portraits, landscapes, vehicles, animals, and artwork).

---

## ? Key Features
- **Deep U-Net Backbone**: Multi-scale feature extraction with 4-level encoder-decoder hierarchy and a 1024-filter bottleneck.
- **Skip Connections**: Direct high-resolution spatial feature propagation to preserve fine-grained structural edges and textures.
- **Multi-Domain Data Ingestion**: Aggregates diverse datasets (celebrities, faces, landscapes, cars, animals, anime) for robust domain generalization.
- **Automated Data Preparation**: Automated grayscale synthesis (`OpenCV`), unified naming, and standardized `[0, 1]` floating-point tensor normalization.
- **Robust Training Pipeline**: Integration of `EarlyStopping` (patience: 20) and `ModelCheckpoint` for optimal weight preservation.

---

## ?? Network Architecture

The network takes a single-channel grayscale input `(256 x 256 x 1)` and outputs a 3-channel RGB reconstruction `(256 x 256 x 3)`:

```
Grayscale Input (256x256x1)
       ?
       ?
[Encoder Level 1] ?? Conv2D (64) + BN + ReLU ??? Skip Connection 1 (256x256x64)
       ? MaxPool (128x128)
       ?
[Encoder Level 2] ?? Conv2D (128) + BN + ReLU ?? Skip Connection 2 (128x128x128)
       ? MaxPool (64x64)
       ?
[Encoder Level 3] ?? Conv2D (256) + BN + ReLU ?? Skip Connection 3 (64x64x256)
       ? MaxPool (32x32)
       ?
[Encoder Level 4] ?? Conv2D (512) + BN + ReLU ?? Skip Connection 4 (32x32x512)
       ? MaxPool (16x16)
       ?
[Bottleneck] ??????? Conv2D (1024) + BN + ReLU (16x16x1024)
       ?
       ?
[Decoder Level 4] ?? UpSample (32x32) + Concat(Skip 4) ??? Conv2D (512) + BN + ReLU
       ?
       ?
[Decoder Level 3] ?? UpSample (64x64) + Concat(Skip 3) ??? Conv2D (256) + BN + ReLU
       ?
       ?
[Decoder Level 2] ?? UpSample (128x128) + Concat(Skip 2) ?? Conv2D (128) + BN + ReLU
       ?
       ?
[Decoder Level 1] ?? UpSample (256x256) + Concat(Skip 1) ?? Conv2D (64) + BN + ReLU
       ?
       ?
[Output Head] ?????? Conv2D (3 filters, 1x1, Sigmoid) ??? Colorized RGB (256x256x3)
```

### Architectural Breakdown:
1. **Encoder (Contracting Path)**:
   - 4 downsampling blocks: Each block contains double `Conv2D(3x3)` layers, `BatchNormalization`, `ReLU` activations, followed by `MaxPooling2D(2x2)`.
   - Feature channels increase progressively: `64 -> 128 -> 256 -> 512`.
2. **Bottleneck**:
   - Double `Conv2D(1024, 3x3)` with `BatchNormalization` capturing deep semantic context.
3. **Decoder (Expansive Path)**:
   - 4 upsampling stages using `UpSampling2D(2x2)` and `Conv2D(2x2)` combined via channel concatenation (`concatenate`) with corresponding encoder skip connections.
   - Preserves both high-level semantic color priors and sharp low-level edge features.
4. **Output Head**:
   - `Conv2D(3, 1x1, activation='sigmoid')` mapping activations directly into normalized RGB space `[0, 1]`.

## ?? Dataset & Data Pipeline

The training dataset integrates multiple Kaggle repositories to ensure generalization across various visual categories:

| Dataset Source | Category | Purpose |
| :--- | :--- | :--- |
| `vishesh1412/celebrity-face-image-dataset` | Portraits / Faces | Skin tone fidelity & facial feature colorization |
| `stoicstatic/face-recognition-dataset` | Human Faces | Broad skin tone and lighting variation |
| `arnaud58/landscape-pictures` | Nature / Scenery | Foliage, skies, water, and earth palette learning |
| `prondeau/the-car-connection-picture-dataset` | Vehicles | Metallic textures, reflections, and urban scenes |
| `vishweshsalodkar/wild-animals` | Wildlife & Animals | Fur patterns, organic textures, and natural lighting |
| `arnaud58/selfie2anime` | Stylized Art / Anime | Artistic palette and vibrant color distribution |

### Preprocessing Steps:
1. **Extraction & Aggregation**: Unification of multi-source images into a singular repository with automated deduplication.
2. **Grayscale Conversion**: Generation of ground-truth input pairs using OpenCV:
   ```python
   gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
   ```
3. **Resizing & Normalization**: Standardized interpolation to `256 x 256` resolution and pixel normalization to `[0.0, 1.0]`.

## ?? Training & Optimization

```python
# Model Compilation Configuration
model.compile(
    optimizer='adam',
    loss='mse',
    metrics=['accuracy']
)

# Training Hyperparameters
history = model.fit(
    gray_images,
    rgb_images,
    validation_split=0.1,
    epochs=200,
    batch_size=16,
    callbacks=callbacks
)
```

- **Loss Function**: Mean Squared Error (MSE) between ground truth RGB and generated RGB.
- **Optimizer**: Adam
- **Batch Size**: 16
- **Maximum Epochs**: 200 (with early stopping)
- **Validation Split**: 10%
- **Callbacks**:
  - `EarlyStopping(monitor='val_loss', patience=20, restore_best_weights=True)`
  - `ModelCheckpoint('best_colorization_model.h5', save_best_only=True, monitor='val_loss')`
